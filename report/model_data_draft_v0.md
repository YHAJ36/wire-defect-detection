# 模型—改进—数据对照（v1，PDF 已生成）

> 用途：为后续实验选型提供“我们做过什么 / 论文做过什么 / 数据是多少 / 出处在哪”的对照底稿。
> 本文件是 PDF 的源稿；PDF 见 `report/模型改进与数据对照_v1.pdf`。只做整理，不改任何实验产物。

## 0. 阅读约定

- **来源类型**：`本项目` / `文献`（P1–P6）/ `网络来源`（网页检索，未核实）。网络来源与文献同列在 §2，文献优先。
- **出处**：本项目写 TSV/日志路径与 run 名；论文写“论文 + 表号 + PDF 页 / 印刷页”。
- **小数口径**：论文保留原表位数；本项目 v_final 保留 4 位（v5 按源精度 3 位）；batch2/3 保留 6 位原值或 2 位 pt。
- **不可比**：不同论文的数据集、类别数、指标定义不同，P/R/mAP 只能做“方向性”对照，不能直接排名。
- **本稿不是论文综述**：网络来源只列候选与风险，未核实的数据不写成结论。

## 1. 按模型族 → 改进类别

> 交叉核对：640 的 v11 行与 `logs/eval_test_640.log` 的 `TEST-RESULT wire_v11_640  mAP50=0.8992  mAP50-95=0.5286  P=0.8887  R=0.8264` 一致；320 各行与 `logs/eval_test_sgd.log` 的表（表头 run/mAP50/mAP50-95/P/R，test、23 张）逐行一致；896 无独立 TEST-RESULT 日志，只能沿用封版报告常量。注意 `runs/*/results.csv` 末行是训练期 val 指标，不等于本表的 best.pt test 指标。

### 2.3 结合当前实验状态的优先级建议

前提：注意力方向已用 n=3 证伪（896/640 区间全部重叠）；当前可信基线是 896 三种子 v11，mAP50 均值 0.9079、区间 [0.9044, 0.9122]；数据集只有 bbox 标注，没有分割掩码；本项目最初基于 P6 的代码框架搭建，P6 的模块可在现有工程内改造，不需要从零复现。排序原则：**先文献、后网络；先低成本、后高成本**。

1. **先做 WIoU**（文献支撑：P2 表 3.1、P5 表 3-4/3-5；网络来源另有 2 篇同场景论文）。只改损失函数，不动网络结构，基线、训练脚本、评估流程全部复用。注意 P2 的 WIoU 行 P=82.4 异常，不能照抄“+0.8 mAP50”，必须自己跑 n=3。
2. **再做 Mask-Guided Copy-Paste，但先解决掩码**（文献支撑：铁路缺陷复制粘贴复现包；本项目只有 bbox）。需先用 bbox 近似掩码，或对少量样本补掩码；同时必须按“先划分后增强”的规则做泄漏核查。
3. **GAN 增强排第三**（文献支撑：焊缝 GAN、AsphaltGAN）。生成式增强成本最高，小数据集容易学到生成伪影；只有在 WIoU 与 Copy-Paste 都做完、且样本不足仍是主要瓶颈时再上。
4. **特征融合（Dy-CCFM / LMAFPN / RepGFPN）排第四**（均有论文题名）。这些模块改动大、参数量与速度都会变，且在 P6 中同族的 AFPN 反而使 mAP50 从 93.3 降到 91.3，必须先证明基线瓶颈在跨尺度融合。
5. **知识蒸馏、NAS、Mamba 放远期**。KD 需要更强教师（当前没有）；NAS 单卡算力不足；Mamba 依赖 CUDA 算子，部署链复杂。AKConv/iRMB 可作为轻量卷积替换的备选，但要先测参数量、GFLOPs 与 FPS。
6. **不建议再作为主方向**：再加注意力模块（CBAM/CA/ECA/GAM/SimAM/Triplet）、单纯换更大输入分辨率、单纯换优化器——这些在本项目已有数据里都没有稳定收益。

> 以上排序只基于“文献支撑强度 × 成本”，不是对效果的承诺；每一项都必须按 n=3、预登记区间、test 集评估的同一套规则执行。

### 本项目的 0.9148

封版 runs/wire_v11_896 的 test mAP50=0.9148；同配置同种子重跑 0.9044，896 三种子基线均值 0.9079（区间 0.9044~0.9122）。0.9148 高出三 seed 上界，偏乐观可能性大。引用时必须同时给出重跑区间，不可只报 0.9148。

### attention 结论

本项目在 896/640 上对 CBAM+BN、Triplet 做了 n=3 重复，test mAP50 区间全部与基线重叠 ⇒ 无可检测增益；640 CBAM+BN 的名义 +1.62pt 在 896 反向、且错开幅度仅 0.13pt，不可信。因此后续不应再把“再加一个注意力模块”作为主方向。

### YOLO26 口径

YOLO26 数字由 ultralytics 8.4.178 产出，v11 由 8.3.180 产出；且 val/test 走 one2many + NMS，不是 YOLO26 的 NMS-free 端到端模式。跨代差异无法拆成“模型差”与“框架版本差”。
